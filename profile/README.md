## What is Molpha?

Molpha is a decentralized oracle protocol that lets anyone turn an HTTP API into cryptographically verifiable data.

Applications and AI agents request data when they need it. Independent verifier nodes fetch the data, reach consensus, produce a threshold signature, and the result can be verified on supported chains with lightweight verifier contracts.

## Why Molpha?

- **Any API** — no predefined feeds or provider onboarding.
- **Built for AI agents** — MCP-native with pay-per-request access.
- **One SDK** — configure APIs, request data, verify signatures, and submit updates across supported chains.
- **Cross-chain by design** — SVM, EVM and Cairo/STARK.
- **USDC-native** — subscriptions, pay-per-request, staking and rewards without a protocol token.
